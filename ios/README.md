# Native Widget Board

The app and widget use the HTTPS origin pinned in `Shared/HostedConnection.swift`.
The reference origin is an owner-private instance. Deploy your own service and update
that origin and the server pairing origin before building a fork. They do not connect
to the unauthenticated localhost prototype.

## Install on your iPhone

1. Run `xcodegen generate` in this directory and open `WidgetBoard.xcodeproj`.
2. Choose your Apple developer team under Signing & Capabilities for **WidgetBoard** and **BoardWidget**. Keep automatic signing enabled.
3. Both targets require Push Notifications, the App Group `group.dev.widgetboard.shared`, and the Keychain Sharing group `dev.widgetboard.shared`. Xcode prefixes the Keychain group with your signing team. If these identifiers are unavailable in your team, change them consistently in `project.yml` and `Shared/HostedConnection.swift`, then regenerate.
4. Connect and trust your iPhone, enable Developer Mode if Xcode requests it, select the phone, and Run the **WidgetBoard** scheme.
5. In the app, select **Continue with ChatGPT**. Complete sign-in and approve **Connect this iPhone**. The app verifies hosted access before saving credentials.
6. Add the **Board** Home Screen widget. It shows your single canvas; there is no board selection. Open the app and tap Reload for an immediate refresh request; iOS controls normal refresh timing.

The widget can read while the app is closed. After a device restart, unlock once before background Keychain access is available. A device connection expires after 90 days; reconnect in the app. Revoke devices from the hosted Site's **Manage connected devices** page.

On iOS 26+, a WidgetKit push handler registers the token and presence of the Board widget with the hosted service. Open the app once after installing to register widgets already on the Home Screen. The connection section reports registration status. Registration retries when the app becomes active, after reconnect/Reload, and during widget timelines. Older iOS versions retain polling. Pushes are silent and do not request permission for alerts.

The client reads the APNs environment from its signed provisioning profile; App Store installs without an embedded profile use production. The server must have an APNs key authorized for that environment and the app topic. Push acceptance is not a guarantee of immediate display; the widget keeps its 15-minute timeline request as a fallback.

## Verification

The `WidgetBoard` Xcode scheme includes `WidgetBoardTests`. Tests validate a synthetic callback generated by the actual server's WebCrypto implementation, rejection of altered or misdirected callbacks, hosted request credentials, and the offline-cache policy. The fixture has no real credentials.

The app shows the complete canvas and connection controls. The widget shows a compact
summary; there is no board-name field or board picker. A Stat can keep a short
comparison in `supportingText` below its styled value.
